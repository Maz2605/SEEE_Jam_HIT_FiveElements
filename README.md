🏰 Game Overview

Humanity is nearly extinct, with only a few survivors left in a ruined world. You play as a powerful sorceress defending the last fortress against monsters invading from another realm.
Using your unique magic, you can purify corrupted creatures and turn them back into humans. Every rescued soul strengthens the final stand of mankind.
A tower-defense game about survival, purification, and protecting the last hope of humanity.

🧠 Technical Skills Used

Object-Oriented Programming (OOP)
SOLID Principles
SRP, OCP, LSP, ISP, DIP applied across gameplay systems
Modular Game Architecture
Event-Driven Logic (C# Events, UnityEvents)
Design Patterns:
Singleton (GameManager, AudioManager)
Factory (enemy / projectile creation)
Strategy (enemy behaviors, attack logic)
Observer (UI updates, health system)
State Pattern (AI states, wave states, animation states)
Object Pooling for optimized spawning
Unity 2D Development: sprites, physics, sorting layers
Animation State Machines (Animator)
Projectile & Combat Systems
Wave Spawning System
Gameplay Optimization (reduced allocations, pooled objects)
